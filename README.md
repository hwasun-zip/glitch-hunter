# GLITCH HUNTER (글리치 헌터)

> 네온 도시에서 꼬마 로봇이 폭주한 AI를 사냥하는 2D 횡스크롤 액션 게임
> "이 AI는 당신의 플레이를 학습한다. 잘하면 더 강해지고, 고전하면 틈을 보인다."

## 플레이 방법

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| Z | 근접 공격 (연타 시 3타 콤보). 휘두를 때마다 에너지 파동이 앞으로 날아감 |
| ↑ + Z | 올려베기: 파동이 대각선 위로 날아감. 점프당 한 번 몸이 떠오름 |
| C | 사격 (5발, 1.6초마다 1발씩 자동 충전) |
| V | 특수 아이템 사용 (완전 방패, 따발총) |
| ↓ (누르고 있기) | 방패: 정면 공격을 막음. 막을 때마다 게이지가 줄고, 바닥나면 방패가 깨져 잠깐 무방비 |
| ↑ 또는 Space | 점프 (길게 누르면 높게, 짧게 누르면 낮게) |
| X | 대시 (짧은 무적, 지나가는 적에게 피해, 쿨타임 0.7초) |
| M | 소리 켜기/끄기 |
| R | 쓰러졌을 때 다시 시작 |

로컬 실행: `index.html`을 브라우저로 열면 바로 실행됩니다. (설치 불필요, 인터넷 연결 필요)

## 처음 하는 사람을 위한 장치 (v1.1)
- **튜토리얼**: 섹터 1을 처음 할 때 7단계(이동, 점프, 3타 콤보, 올려베기, 대시, 방패, 사격)를 직접 해 보며 진행. Enter로 건너뛰기. 진행 중에는 적이 멈추고, 끝난 뒤부터 섹터 1 시간을 측정해 실력 점수에 영향이 없도록 함. 완료/건너뛰기와 소요 시간을 기록
- **상황별 안내(TIP)**: 적, 장애물, 보스 패턴을 처음 만날 때 화면 위쪽에 큰 안내판으로 대처법을 표시. 동시에 여러 개가 뜨면 차례대로. 두 그룹 모두 동일

### 캐릭터 옆 자원 UI (v1.5)
HP는 머리 위에 항상 표시(맞으면 흰 잔상), 대시 쿨다운(보라 원형), 방패 게이지(세로 막대, 깨지면 빨강), 탄창(리볼버 모양 5칸, 남은 발 수와 충전 진행)은 **로봇의 등 뒤쪽**에 필요할 때만 표시. 다 차면 반짝하고 사라짐

### 아이템 (v1.7)
적이 쓰러질 때 35% 확률로 떨어지고(작은 바이러스는 10%), 10초 뒤 깜빡이다 사라짐. 보스는 무력화에 성공할 때마다 회복(+30)과 특수 아이템을 떨어뜨림
| 아이템 | 효과 | 사용 |
|---|---|---|
| 회복 +10 / +30 / +50 / 풀충전 | HP 회복 (클수록 드묾: 비율 30 / 18 / 7 / 2) | 먹으면 바로 |
| 탄약 | 총알 +1 | 먹으면 바로 |
| 완전 방패 | 4초 동안 무엇에 맞아도 HP가 줄지 않음 (금색 오라) | 1칸 보관 후 V |
| 따발총 | 5초 동안 C를 누르고 있으면 탄 소모 없이 연사 | 1칸 보관 후 V |

특수 아이템은 하나만 들 수 있고 다음 섹터로 들고 갈 수 있어서 "지금 쓸까, 보스까지 아낄까"라는 판단이 생김. 줍기와 사용은 모두 기록

## 1페이지 기획서

### 한 줄 소개
보스의 예고를 읽고 피하고 반격하는 2D 횡스크롤 보스 액션. 플레이어의 실력에 맞춰 난이도가 조정된다.

### 진행 구조
섹터 1 (연습: 잡몹) → 섹터 2 (응용: 장애물과 방패 잡몹) → 섹터 3 (심화: 새 몬스터 2종) → 보스 섹터 (시험) → 엔딩 결과 화면(랭크), 한 판 6~9분

### 섹터 2: 장애물 (모두 예고가 있고 방패로 못 막음)
| 장애물 | 예고 | 대처 |
|---|---|---|
| 레이저 벽 | 가는 붉은 선이 깜빡임 | 꺼졌을 때 지나가거나 대시(무적)로 통과 |
| 전기 바닥 | 노란 불꽃이 튐 | 위쪽 발판으로 피하거나 꺼졌을 때 지나감 |
| 낙하 글리치 블록 | 바닥에 붉은 그림자가 커짐 | 그림자 밖으로 이동 |

### 섹터 2: 방패 잡몹 "방화벽 가드"
정면에서 수평으로 들어오는 공격(근접, 파동, 사격, 대시)을 모두 막음. 등 뒤나 위에서 치면 맞음. 플레이어가 뒤로 가면 돌아서는 데 0.7초가 걸려 그 사이가 공격 기회. 대시로 정면을 뚫고 지나가 뒤로 돌아가는 것이 정석. 가까이 가면 0.65초 예고 후 방패로 밀침(걸어오다 몸에 닿는 것만으로는 피해 없음)

### 섹터 3: 새 몬스터 2종 ("하나씩 소개 → 조합" 구성)
섹터 3은 분열 바이러스 둘 → 순간이동 해커 단독 → 전기 바닥 → **"앞은 방패 잡몹, 뒤는 해커"** 조합 → 바이러스 떼와 드론, 해커가 낙하 블록 위에서 나오는 구간 순서. 새 요소를 하나씩 익힌 뒤 섞어서 시험하고, 마지막은 지금까지 배운 규칙(방패는 정면만, 대시로 뚫기, 돌아서기)을 모두 쓰게 하는 레벨 디자인
| 몬스터 | 예고 | 대처 | 시험하는 기술 |
|---|---|---|---|
| 분열 바이러스 | 웅크리며 "!" 후 튀어올라 덮침 | 처치하면 "SPLIT!"과 함께 작고 빠른 2마리로 한 번 분열(분열 직후 0.5초는 무적이라 반드시 두 번 처치). 3타 넉백과 파동으로 한꺼번에 정리 | 다수 상대, 공격 범위 |
| 순간이동 해커 | 플레이어 **등 뒤** 바닥에 초록 표식과 실루엣 | 표식 쪽으로 돌아서 방패(정면만 막힘)를 들거나 대시로 회피. **2연속**으로 오며 두 번째는 예고가 짧음. 끝나면 빈틈 | 방향 판단, 방패 방향 |

### 엔딩 랭크
한 판(섹터 1부터 보스까지) 동안의 기록으로 결정. S: 쓰러짐 0회 + 받은 피해 120 이하 / A: 쓰러짐 1회 이하 + 피해 250 이하 / B: 쓰러짐 3회 이하 / C: 그 외

### 몬스터
- 근접 돌진형: 다가와서 들이받음
- 원거리형: 거리를 두고 투사체 발사

### 보스 패턴 (모든 패턴에 예고가 있음)

| 패턴 | 예고 | 대처 |
|---|---|---|
| 돌진 | 바닥에 붉은 직선 표시 | 점프나 대시로 넘기 |
| 내려찍기 | 착지 지점에 원형 장판 | 장판 밖으로 이동 |
| 부채꼴 탄막 | 보스가 팔을 들고 빛남 | 탄 사이 빈틈으로 이동 |
| 필살기 (무력화) | 기 모으기 + 무력화 게이지 | 제한 시간 내 게이지를 깎으면 그로기, 실패 시 HP 50% 피해 |

### 난이도 규칙: 상승 + 적응 보정
- 기본 상승: 섹터마다 난이도 +10%
- 적응 보정: 이전 섹터의 피격 횟수와 클리어 시간으로 실력 점수를 매겨 -20%~+20% 보정
- 조정 대상: 예고 시간, 보스 공격 속도, 몬스터 수, 보스 HP
- 구현은 규칙 기반이며, 게임 안에서는 "AI가 학습하는 것처럼" 보이도록 연출

### 검증 (A/B 테스트)
- 플레이어마다 무작위로 "보정 켬 / 끔" 배정
- 기록: 섹터별 클리어 시간, 패턴별 피격, 사망, 무력화 성공 여부, 재도전 여부
- 성공 기준: 보정 켬 그룹에서 "아슬아슬한 클리어"(남은 HP 30% 이하)가 늘고 중도 포기가 줄어드는가

### 3층 구현 상세: 적응형 난이도와 A/B 테스트
- **그룹 배정**: 처음 접속할 때 무작위로 `control`(보정 끔) 또는 `adaptive`(보정 켬)에 배정하고 브라우저에 저장. 같은 사람이 두 그룹에 섞이지 않음
- **화면 동일**: 두 그룹 모두 보스 등장 시 "CORE.EXE가 당신의 전투 데이터를 분석했다"가 뜸. 차이는 수치뿐이라 문구 효과가 섞이지 않음
- **실력 점수** (-1 ~ 1): 섹터의 피격 횟수(가중치 0.6)와 클리어 시간(0.4)을 기준값(섹터 1: 피격 6회, 100초 / 섹터 2: 피격 8회, 130초 / 섹터 3: 피격 9회, 140초)과 비교. 그 섹터에서 죽은 횟수는 1회당 피격 3회로 환산. 클리어한 섹터들의 평균을 사용
- **난이도 배율** (섹터 2와 보스에 적용)
  - 기본 상승(두 그룹 공통): 섹터 2 x1.08, 섹터 3 x1.12, 보스 x1.16 (섹터 3 추가 후에도 보스는 그대로)
  - control: 기본 상승만
  - adaptive: 기본 상승 x (1 + 실력 점수 x 0.2) x (1 - 그 섹터에서 죽은 횟수 x 0.05)
  - 배율은 적과 보스의 HP, 이동/돌진/탄 속도, 무력화 게이지에 곱하고, 예고와 쉬는 시간, 장애물 주기는 배율로 나눔
- **무력화 기록 형식**: 성공은 `O`, 실패는 `X` + 남은 게이지 % (예: `X94` = 94% 남기고 실패 → 방법을 몰랐을 가능성, `X8` = 아슬아슬하게 실패)
- **수집 항목** (시도 단위, 한 판을 끝내면 run_complete로 전체 시간, 받은 피해, 그리고 상세 열에 랭크와 쓰러진 횟수도 기록): 그룹, 섹터, 시도 번호, 결과(clear/death/quit), 소요 시간, 피격 횟수, 받은 피해, 사망 원인 패턴, 패턴별 피격 수, 무력화 성공/실패, 난이도 배율, 실력 점수, 남은 HP
- **익명성**: 무작위 ID만 사용. 게임 화면에 수집 안내 문구 표시
- **개발자 테스트 분리**: 주소 끝에 `?debug=1`을 붙이면 기록에 debug=1이 표시되어 분석에서 제외 가능(L 키로 로그 파일 다운로드). `?debug=2`는 화면에 그룹과 난이도까지 표시. `?tutorial=1`은 튜토리얼 다시 보기
- **수신**: Google Apps Script 웹 앱 → 구글 시트 (`apps-script.gs`)

### v1.0 플레이테스트 계획 (데이터를 보기 전에 정한 기준)
- **기간 중 원칙**: 플레이테스트 동안 게임 내용을 바꾸지 않음 (버전이 섞이면 비교가 깨짐)
- **대상**: 지인과 외부 커뮤니티(처음 하는 사람). 링크의 `?src=`로 출처를 구분해 따로 분석
- **검증 질문과 지표**
  | 질문 | 지표 |
  |---|---|
  | 적응형 난이도가 효과가 있는가 | 그룹별 보스 클리어율, 아슬아슬한 클리어(남은 HP 30% 이하) 비율, 이탈률 |
  | 무력화가 공정한가 | 처음 하는 사람의 무력화 성공률 50% 이상, 실패 시 남은 게이지 분포 |
  | 어디가 벽인가 | 섹터별 사망 원인 1위 |
- **한계**: 표본이 작은 소규모 파일럿 테스트. 결과는 방향을 확인하는 용도로 해석
- **제외**: debug=1 기록, 개발자 플레이어 ID
